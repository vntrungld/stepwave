# M0 + M1 Core Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Rust workspace and CI, the `stepwave-core` DSP pipeline (STFT → 32-band ERB mask → smoothing → shared L/R gain → iSTFT → limiter) with a static-EQ mask source, and the offline `stepwave-cli` WAV renderer.

**Architecture:** `core` is a library with one file per DSP stage and a `Processor` that wires them together. Every buffer is allocated in the constructor, so `process()` is real-time safe. The mask comes from a `MaskSource` trait object: `StaticEqMask` now, a model in M4. `cli` is a thin binary that reads/writes WAV with `hound` and drives `Processor`.

**Tech Stack:** Rust stable (1.98, edition 2021). Crates: `realfft`, `apodize`, `biquad`, `serde`/`serde_json`, `thiserror`, `hound`, `clap`, `anyhow`, `approx` (dev), `tempfile` (dev). CI is GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-27-m0-m1-core-design.md`

All code in this plan was compiled and tested in a scratch copy before it was written down: 41 tests pass, and `cargo fmt --check` and `cargo clippy --workspace --all-targets -- -D warnings` are clean on rustc 1.98.1.

## Global Constraints

- Sample rate is 48 000 Hz only. STFT window is 960 (20 ms), hop is 480 (10 ms), 481 bins, with a periodic sqrt-Hann window.
- 32 ERB bands, spaced on `erb_rate(f) = 21.4·log10(1 + 0.00437 f)` from 50 Hz to 20 kHz.
- The same gain array is applied to the L and R spectra, never per-channel gains.
- `Processor::process` never allocates, locks, logs or panics. Everything is allocated in the constructor.
- Reported latency is 960 samples.
- Limiter ceiling is −1 dBFS (sample peak), with a stereo-linked gain, instant attack and 50 ms release.
- Smoother: attack coefficient `1 − e^(−10/5)`, release coefficient `1 − e^(−10/80)`, applied per 10 ms frame. The first frame jumps straight to the target.
- `cargo fmt --all --check` and `cargo clippy --workspace --all-targets -- -D warnings` must pass after every task.
- Test signals are synthetic only. Never add game assets.
- Commit format is conventional commits (`feat(core): …`), and every commit message ends with the trailer `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Code, comments and docs are in English.

## Review Focus

- **WAV at 44.1 kHz or with more than 2 channels:** the CLI exits non-zero with a message that names the problem and writes no output file. Covered in Task 8 (`rejects_44k1_input`, `rejects_multichannel_input`).
- **Input shorter than the latency (100 samples):** the output has the same length and the program does not crash. Covered in Task 8 (`short_input_keeps_its_length`).
- **Mask source emits NaN/inf:** audio passes through at unity instead of turning into NaN forever. Covered in Task 7 (`non_finite_mask_falls_back_to_unity`).
- **Host passes L/R blocks of different lengths:** no panic, and only the common prefix is processed. Covered in Task 7 (`mismatched_block_lengths_do_not_panic`).
- **Profile with no `fallback_eq`, or an unknown filter type:** the empty list is accepted as flat, and an unknown type is a readable JSON error. Covered in Task 1 (`accepts_empty_fallback_eq`, `rejects_unknown_filter_type`).

//! Per-game profile (`profiles/*.json`).

use serde::Deserialize;

use crate::CoreError;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum EqType {
    Lowshelf,
    Highshelf,
    Peak,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
pub struct EqBand {
    #[serde(rename = "type")]
    pub kind: EqType,
    pub freq: f32,
    pub gain: f32,
    pub q: f32,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
pub struct MatchRules {
    #[serde(default)]
    pub windows: Vec<String>,
    #[serde(default)]
    pub linux: Vec<String>,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
pub struct Profile {
    pub id: String,
    pub name: String,
    #[serde(rename = "match")]
    pub match_rules: MatchRules,
    /// Model path; unused until M4.
    pub model: String,
    /// Footstep boost strength; unused until M4.
    pub strength_db: f32,
    #[serde(default)]
    pub fallback_eq: Vec<EqBand>,
    #[serde(default)]
    pub preamp_db: f32,
}

impl Profile {
    pub fn from_json(json: &str) -> Result<Self, CoreError> {
        let profile: Profile = serde_json::from_str(json)?;
        profile.validate()?;
        Ok(profile)
    }

    fn validate(&self) -> Result<(), CoreError> {
        if !self.preamp_db.is_finite() || !self.strength_db.is_finite() {
            return Err(CoreError::InvalidProfile(
                "preamp_db and strength_db must be finite".into(),
            ));
        }
        for (i, band) in self.fallback_eq.iter().enumerate() {
            if !(band.freq > 0.0 && band.freq < 24_000.0) {
                return Err(CoreError::InvalidProfile(format!(
                    "fallback_eq[{i}]: freq {} must be in (0, 24000)",
                    band.freq
                )));
            }
            if !(band.q > 0.0 && band.q.is_finite()) {
                return Err(CoreError::InvalidProfile(format!(
                    "fallback_eq[{i}]: q {} must be > 0",
                    band.q
                )));
            }
            if !band.gain.is_finite() {
                return Err(CoreError::InvalidProfile(format!(
                    "fallback_eq[{i}]: gain must be finite"
                )));
            }
        }
        Ok(())
    }
}
```

//! 32-band ERB layout and band → FFT-bin gain interpolation.

pub const NUM_BANDS: usize = 32;
pub const MIN_HZ: f32 = 50.0;
pub const MAX_HZ: f32 = 20_000.0;

/// Glasberg & Moore ERB-rate (ERB number) of a frequency in Hz.
pub fn erb_rate(hz: f32) -> f32 {
    21.4 * (1.0 + 0.00437 * hz).log10()
}

/// Inverse of [`erb_rate`].
pub fn erb_rate_to_hz(rate: f32) -> f32 {
    (10f32.powf(rate / 21.4) - 1.0) / 0.00437
}

/// Interpolation of one FFT bin between two neighbouring bands.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct BinWeight {
    pub lo: usize,
    pub hi: usize,
    pub w_lo: f32,
    pub w_hi: f32,
}

#[derive(Debug, Clone)]
pub struct ErbBands {
    centres_hz: [f32; NUM_BANDS],
    bin_weights: Vec<BinWeight>,
}

impl ErbBands {
    /// Allocates the per-bin table; call at init time only.
    pub fn new(sample_rate: u32, fft_size: usize) -> Self {
        let lo = erb_rate(MIN_HZ);
        let hi = erb_rate(MAX_HZ);
        let step = (hi - lo) / (NUM_BANDS - 1) as f32;
        let mut rates = [0.0f32; NUM_BANDS];
        let mut centres_hz = [0.0f32; NUM_BANDS];
        for b in 0..NUM_BANDS {
            rates[b] = lo + step * b as f32;
            centres_hz[b] = erb_rate_to_hz(rates[b]);
        }

        let bins = fft_size / 2 + 1;
        let bin_hz = sample_rate as f32 / fft_size as f32;
        let bin_weights = (0..bins)
            .map(|k| {
                let r = erb_rate(k as f32 * bin_hz);
                if r <= rates[0] {
                    BinWeight {
                        lo: 0,
                        hi: 0,
                        w_lo: 1.0,
                        w_hi: 0.0,
                    }
                } else if r >= rates[NUM_BANDS - 1] {
                    let last = NUM_BANDS - 1;
                    BinWeight {
                        lo: last,
                        hi: last,
                        w_lo: 1.0,
                        w_hi: 0.0,
                    }
                } else {
                    let pos = (r - rates[0]) / step;
                    let lo = (pos.floor() as usize).min(NUM_BANDS - 2);
                    let w_hi = pos - lo as f32;
                    BinWeight {
                        lo,
                        hi: lo + 1,
                        w_lo: 1.0 - w_hi,
                        w_hi,
                    }
                }
            })
            .collect();

        Self {
            centres_hz,
            bin_weights,
        }
    }

    pub fn centres_hz(&self) -> &[f32; NUM_BANDS] {
        &self.centres_hz
    }

    pub fn bin_weights(&self) -> &[BinWeight] {
        &self.bin_weights
    }

    /// Interpolates band gains (dB) onto FFT bins (dB). Real-time safe.
    pub fn expand(&self, band_db: &[f32; NUM_BANDS], bin_db: &mut [f32]) {
        for (out, w) in bin_db.iter_mut().zip(&self.bin_weights) {
            *out = band_db[w.lo] * w.w_lo + band_db[w.hi] * w.w_hi;
        }
    }
}
```

**Interfaces:**
- Consumes: `realfft`, `apodize`.
- Produces:
  - `stft::{SAMPLE_RATE: u32 = 48_000, WINDOW: usize = 960, HOP: usize = 480, BINS: usize = 481}`
  - `stft::StftChannel::new()` and `StftChannel::reset(&mut self)`
  - `stft::Stft::new()`
  - `Stft::analyze(&mut self, ch: &mut StftChannel, hop_in: &[f32], spectrum: &mut [Complex<f32>])`: `hop_in` has ≥ HOP samples and `spectrum` has BINS values
  - `Stft::synthesize(&mut self, ch: &mut StftChannel, spectrum: &mut [Complex<f32>], hop_out: &mut [f32])`: clobbers `spectrum` and writes HOP samples
  - Timing contract: the output hop from frame k equals input hop k−1 (a delay of HOP). The processor's input buffering adds another HOP, for a total of WINDOW.

Key facts for the implementer:
- `apodize::hanning_iter(n)` returns a **symmetric** window as `f64`. Taking `n = WINDOW + 1` and dropping the last point gives the periodic window. With 50 % overlap, sqrt-Hann on analysis and on synthesis multiply to Hann, which sums to exactly 1.
- `realfft`'s inverse is **unnormalised**, so scale by `1/WINDOW`.
- `realfft`'s inverse returns `Err` if the imaginary part of the DC or Nyquist bin is non-zero. Zero them before calling it.

        for (hin, hout) in input.chunks(HOP).zip(output.chunks_mut(HOP)) {

            err += e * e;
            sig += (input[n - HOP] as f64).powi(2);

        let snr_db = 10.0 * (sig / err).log10();
        assert!(snr_db > 90.0, "reconstruction SNR {snr_db:.1} dB");

//! Streaming STFT / iSTFT: 20 ms sqrt-Hann window, 10 ms hop, 48 kHz.

use std::sync::Arc;

use realfft::num_complex::Complex;
use realfft::{ComplexToReal, RealFftPlanner, RealToComplex};

pub const SAMPLE_RATE: u32 = 48_000;
pub const WINDOW: usize = 960;
pub const HOP: usize = 480;
pub const BINS: usize = WINDOW / 2 + 1;

/// Per-channel streaming state: analysis history and overlap-add accumulator.
pub struct StftChannel {
    history: Vec<f32>,
    ola: Vec<f32>,
}

impl StftChannel {
    pub fn new() -> Self {
        Self {
            history: vec![0.0; WINDOW],
            ola: vec![0.0; WINDOW],
        }
    }

    pub fn reset(&mut self) {
        self.history.fill(0.0);
        self.ola.fill(0.0);
    }

/// Shared FFT plans, window and scratch. One instance serves any number of channels.
pub struct Stft {
    fwd: Arc<dyn RealToComplex<f32>>,
    inv: Arc<dyn ComplexToReal<f32>>,
    window: Vec<f32>,
    time: Vec<f32>,
    fwd_scratch: Vec<Complex<f32>>,
    inv_scratch: Vec<Complex<f32>>,
}

impl Stft {
    pub fn new() -> Self {
        let mut planner = RealFftPlanner::<f32>::new();
        let fwd = planner.plan_fft_forward(WINDOW);
        let inv = planner.plan_fft_inverse(WINDOW);
        // apodize yields a symmetric window; N+1 points minus the last gives the periodic one.
        let window = apodize::hanning_iter(WINDOW + 1)
            .take(WINDOW)
            .map(|w| (w as f32).sqrt())
            .collect();
        let fwd_scratch = fwd.make_scratch_vec();
        let inv_scratch = inv.make_scratch_vec();
        Self {
            fwd,
            inv,
            window,
            time: vec![0.0; WINDOW],
            fwd_scratch,
            inv_scratch,
        }
    }

    /// Pushes one hop of input and writes the windowed spectrum (`BINS` values).
    pub fn analyze(&mut self, ch: &mut StftChannel, hop_in: &[f32], spectrum: &mut [Complex<f32>]) {
        ch.history.copy_within(HOP.., 0);
        ch.history[WINDOW - HOP..].copy_from_slice(&hop_in[..HOP]);
        for ((t, &x), &w) in self.time.iter_mut().zip(&ch.history).zip(&self.window) {
            *t = x * w;
        }
        // Lengths are fixed at construction, so this cannot fail.
        let _ = self
            .fwd
            .process_with_scratch(&mut self.time, spectrum, &mut self.fwd_scratch);
    }

    /// Inverse-transforms `spectrum` (clobbered), overlap-adds, and emits one hop of output.
    pub fn synthesize(
        &mut self,
        ch: &mut StftChannel,
        spectrum: &mut [Complex<f32>],
        hop_out: &mut [f32],
    ) {
        // A real signal has purely real DC and Nyquist bins; realfft checks this.
        spectrum[0].im = 0.0;
        spectrum[BINS - 1].im = 0.0;
        let _ = self
            .inv
            .process_with_scratch(spectrum, &mut self.time, &mut self.inv_scratch);
        let scale = 1.0 / WINDOW as f32;
        for ((acc, &t), &w) in ch.ola.iter_mut().zip(&self.time).zip(&self.window) {
            *acc += t * w * scale;
        }
        hop_out[..HOP].copy_from_slice(&ch.ola[..HOP]);
        ch.ola.copy_within(HOP.., 0);
        ch.ola[WINDOW - HOP..].fill(0.0);
    }
}

impl Default for Stft {
    fn default() -> Self {
        Self::new()
    }
}

/// Static EQ from the profile's `fallback_eq` + `preamp_db`, sampled at the ERB band centres.
pub struct StaticEqMask {
    gains_db: [f32; NUM_BANDS],
}

impl StaticEqMask {
    pub fn from_profile(profile: &Profile) -> Self {
        let bands = ErbBands::new(SAMPLE_RATE, WINDOW);
        let mut gains_db = [0.0; NUM_BANDS];
        for (g, &hz) in gains_db.iter_mut().zip(bands.centres_hz()) {
            *g = eq_response_db(&profile.fallback_eq, hz, SAMPLE_RATE as f32) + profile.preamp_db;
        }
        Self { gains_db }
    }

    pub fn gains_db(&self) -> &[f32; NUM_BANDS] {
        &self.gains_db
    }
}

impl MaskSource for StaticEqMask {
    fn next_mask(&mut self, _mid: &[Complex<f32>], gains_db: &mut [f32; NUM_BANDS]) {
        *gains_db = self.gains_db;
    }
}

/// Summed magnitude response (dB) of a chain of RBJ biquads at `hz`.
pub fn eq_response_db(bands: &[EqBand], hz: f32, sample_rate: f32) -> f32 {
    bands
        .iter()
        .map(|b| biquad_response_db(b, hz, sample_rate))
        .sum()
}

fn biquad_response_db(band: &EqBand, hz: f32, sample_rate: f32) -> f32 {
    let kind = match band.kind {
        EqType::Lowshelf => Type::LowShelf(band.gain),
        EqType::Highshelf => Type::HighShelf(band.gain),
        EqType::Peak => Type::PeakingEQ(band.gain),
    };
    // Profile validation guarantees parameters biquad accepts.
    let Ok(c) = Coefficients::<f32>::from_params(kind, sample_rate.hz(), band.freq.hz(), band.q)
    else {
        return 0.0;
    };
    let w = 2.0 * std::f64::consts::PI * hz as f64 / sample_rate as f64;
    let z1 = Complex::from_polar(1.0, -w); // z^-1
    let z2 = z1 * z1;
    let num = Complex::new(c.b0 as f64, 0.0) + z1 * c.b1 as f64 + z2 * c.b2 as f64;
    let den = Complex::new(1.0, 0.0) + z1 * c.a1 as f64 + z2 * c.a2 as f64;
    (20.0 * (num.norm() / den.norm()).log10()) as f32
}

//! Per-band one-pole gain smoothing in the dB domain, updated once per frame.

use crate::erb::NUM_BANDS;

pub const FRAME_MS: f32 = 10.0;
pub const ATTACK_MS: f32 = 5.0;
pub const RELEASE_MS: f32 = 80.0;

pub struct Smoother {
    state: [f32; NUM_BANDS],
    initialized: bool,
    attack: f32,
    release: f32,
}

impl Smoother {
    pub fn new() -> Self {
        Self {
            state: [0.0; NUM_BANDS],
            initialized: false,
            attack: 1.0 - (-FRAME_MS / ATTACK_MS).exp(),
            release: 1.0 - (-FRAME_MS / RELEASE_MS).exp(),
        }
    }

    /// Next state; the first call jumps straight to `target` (no fade-in at startup).
    pub fn process(&mut self, target: &[f32; NUM_BANDS], out: &mut [f32; NUM_BANDS]) {
        if !self.initialized {
            self.state = *target;
            self.initialized = true;
        } else {
            for (s, &t) in self.state.iter_mut().zip(target) {
                let coef = if t > *s { self.attack } else { self.release };
                *s += (t - *s) * coef;
            }
        }
        *out = self.state;
    }

    pub fn reset(&mut self) {
        self.state = [0.0; NUM_BANDS];
        self.initialized = false;
    }
}

impl Default for Smoother {
    fn default() -> Self {
        Self::new()
    }
}

//! Stereo-linked sample-peak limiter, −1 dBFS ceiling, instant attack, no lookahead.
//! True-peak detection is deferred (see the M0+M1 spec).

pub const CEILING_DB: f32 = -1.0;
pub const RELEASE_MS: f32 = 50.0;

pub struct Limiter {
    ceiling: f32,
    release: f32,
    gain: f32,
}

impl Limiter {
    pub fn new(sample_rate: u32) -> Self {
        let release_samples = RELEASE_MS * 1e-3 * sample_rate as f32;
        Self {
            ceiling: 10f32.powf(CEILING_DB / 20.0),
            release: 1.0 - (-1.0 / release_samples).exp(),
            gain: 1.0,
        }
    }

    pub fn ceiling(&self) -> f32 {
        self.ceiling
    }

    /// Limits both channels in place with one shared gain. Real-time safe.
    pub fn process(&mut self, left: &mut [f32], right: &mut [f32]) {
        for (l, r) in left.iter_mut().zip(right.iter_mut()) {
            let peak = l.abs().max(r.abs());
            let mut g = self.gain + (1.0 - self.gain) * self.release;
            if peak * g > self.ceiling {
                g = self.ceiling / peak;
            }
            self.gain = g;
            *l *= g;
            *r *= g;
        }
    }

    pub fn reset(&mut self) {
        self.gain = 1.0;
    }
}

How it works: for each sample, the processor stores the input into a hop buffer and replaces it with the matching sample of the previous frame's output. When the hop fills, `run_frame` does the following:
1. Analyse L and R.
2. Compute mid = (L+R)/2 in the spectral domain.
3. Get the mask, then smooth it. A non-finite result falls back to 0 dB and the smoother is reset.
4. Expand the band gains to bins and convert dB to linear.
5. Multiply the same gains into L and R.
6. Synthesize.

After the sample loop, the limiter runs over the block.

    let ab: f64 = a.iter().zip(b).map(|(&x, &y)| x as f64 * y as f64).sum();
    ab / (energy(a) * energy(b)).sqrt()
}

/// Average power ratio (dB) of output vs input in a ±2 % band around `hz`.
fn measured_gain_db(x: &[f32], y: &[f32], hz: f32) -> f32 {
    const N: usize = 8192;
    let mut planner = RealFftPlanner::<f32>::new();
    let fft = planner.plan_fft_forward(N);
    let mut spec = fft.make_output_vec();
    let bin_hz = 48_000.0 / N as f32;
    let (k0, k1) = (
        ((hz * 0.98) / bin_hz) as usize,
        ((hz * 1.02) / bin_hz) as usize + 1,
    );
    let mut power = |sig: &[f32]| -> f64 {
        let mut total = 0.0;
        for frame in sig.as_chunks::<N>().0 {
            let mut buf: Vec<f32> = frame
                .iter()
                .enumerate()
                .map(|(i, &v)| {
                    let w = 0.5 - 0.5 * (2.0 * std::f32::consts::PI * i as f32 / N as f32).cos();
                    v * w
                })
                .collect();
            fft.process(&mut buf, &mut spec).unwrap();
            total += spec[k0..k1]
                .iter()
                .map(|c| c.norm_sqr() as f64)
                .sum::<f64>();
        }
        total
    };
    (10.0 * (power(y) / power(x)).log10()) as f32
}

//! The full stereo pipeline. Everything is allocated in the constructor; `process` is
//! real-time safe (no allocation, locks, logging or panics).

use realfft::num_complex::Complex;

use crate::erb::{ErbBands, NUM_BANDS};
use crate::limiter::Limiter;
use crate::mask::{MaskSource, StaticEqMask};
use crate::profile::Profile;
use crate::smoother::Smoother;
use crate::stft::{Stft, StftChannel, BINS, HOP, SAMPLE_RATE, WINDOW};
use crate::CoreError;

pub struct Processor {
    stft: Stft,
    left: StftChannel,
    right: StftChannel,
    in_l: Vec<f32>,
    in_r: Vec<f32>,
    out_l: Vec<f32>,
    out_r: Vec<f32>,
    pos: usize,
    spec_l: Vec<Complex<f32>>,
    spec_r: Vec<Complex<f32>>,
    spec_mid: Vec<Complex<f32>>,
    mask: Box<dyn MaskSource>,
    target_db: [f32; NUM_BANDS],
    smoothed_db: [f32; NUM_BANDS],
    smoother: Smoother,
    bands: ErbBands,
    bin_gain: Vec<f32>,
    limiter: Limiter,
}

impl Processor {
    /// Pipeline with the profile's static-EQ mask.
    pub fn new(profile: &Profile, sample_rate: u32) -> Result<Self, CoreError> {
        Self::with_mask(Box::new(StaticEqMask::from_profile(profile)), sample_rate)
    }

    /// Pipeline with any mask source (e.g. `UnityMask` for bypass, a model in M4).
    pub fn with_mask(mask: Box<dyn MaskSource>, sample_rate: u32) -> Result<Self, CoreError> {
        if sample_rate != SAMPLE_RATE {
            return Err(CoreError::UnsupportedSampleRate(sample_rate));
        }
        Ok(Self {
            stft: Stft::new(),
            left: StftChannel::new(),
            right: StftChannel::new(),
            in_l: vec![0.0; HOP],
            in_r: vec![0.0; HOP],
            out_l: vec![0.0; HOP],
            out_r: vec![0.0; HOP],
            pos: 0,
            spec_l: vec![Complex::default(); BINS],
            spec_r: vec![Complex::default(); BINS],
            spec_mid: vec![Complex::default(); BINS],
            mask,
            target_db: [0.0; NUM_BANDS],
            smoothed_db: [0.0; NUM_BANDS],
            smoother: Smoother::new(),
            bands: ErbBands::new(SAMPLE_RATE, WINDOW),
            bin_gain: vec![0.0; BINS],
            limiter: Limiter::new(SAMPLE_RATE),
        })
    }

    /// Algorithmic latency to report to the host.
    pub fn latency_samples(&self) -> usize {
        WINDOW
    }

    /// Processes a stereo block of any size in place. If the slices differ in length,
    /// only the common prefix is processed.
    pub fn process(&mut self, left: &mut [f32], right: &mut [f32]) {
        let n = left.len().min(right.len());
        let (left, right) = (&mut left[..n], &mut right[..n]);
        for (l, r) in left.iter_mut().zip(right.iter_mut()) {
            self.in_l[self.pos] = *l;
            self.in_r[self.pos] = *r;
            *l = self.out_l[self.pos];
            *r = self.out_r[self.pos];
            self.pos += 1;
            if self.pos == HOP {
                self.pos = 0;
                self.run_frame();
            }
        }
        self.limiter.process(left, right);
    }

    pub fn reset(&mut self) {
        self.left.reset();
        self.right.reset();
        self.in_l.fill(0.0);
        self.in_r.fill(0.0);
        self.out_l.fill(0.0);
        self.out_r.fill(0.0);
        self.pos = 0;
        self.smoother.reset();
        self.limiter.reset();
    }

    fn run_frame(&mut self) {
        self.stft
            .analyze(&mut self.left, &self.in_l, &mut self.spec_l);
        self.stft
            .analyze(&mut self.right, &self.in_r, &mut self.spec_r);
        for ((m, &l), &r) in self.spec_mid.iter_mut().zip(&self.spec_l).zip(&self.spec_r) {
            *m = (l + r) * 0.5;
        }

        self.mask.next_mask(&self.spec_mid, &mut self.target_db);
        self.smoother
            .process(&self.target_db, &mut self.smoothed_db);
        if self.smoothed_db.iter().any(|g| !g.is_finite()) {
            // Bad mask: unity gain for this frame and start the smoother fresh.
            self.smoothed_db = [0.0; NUM_BANDS];
            self.smoother.reset();
        }
        self.bands.expand(&self.smoothed_db, &mut self.bin_gain);
        for g in self.bin_gain.iter_mut() {
            *g = 10f32.powf(*g / 20.0);
        }

        // Stereo image: the SAME gain goes to L and R.
        for ((l, r), &g) in self
            .spec_l
            .iter_mut()
            .zip(self.spec_r.iter_mut())
            .zip(&self.bin_gain)
        {
            *l *= g;
            *r *= g;
        }
        self.stft
            .synthesize(&mut self.left, &mut self.spec_l, &mut self.out_l);
        self.stft
            .synthesize(&mut self.right, &mut self.spec_r, &mut self.out_r);
    }
}

//! `stepwave-cli in.wav out.wav --profile cs2 [--bypass]`

use std::path::{Path, PathBuf};
use std::time::Instant;

use anyhow::{bail, Context, Result};
use clap::Parser;
use hound::{SampleFormat, WavReader, WavSpec, WavWriter};
use stepwave_core::stft::{HOP, SAMPLE_RATE};
use stepwave_core::{Processor, Profile, UnityMask};

#[derive(Parser)]
#[command(version, about = "Render a WAV through the stepwave pipeline")]
struct Args {
    /// Input WAV (48 kHz, mono or stereo)
    input: PathBuf,
    /// Output WAV (48 kHz stereo, 32-bit float)
    output: PathBuf,
    /// Profile id (resolved to profiles/<id>.json) or a path to a profile JSON
    #[arg(long)]
    profile: String,
    /// Run the chain with a unity mask, for A/B listening
    #[arg(long)]
    bypass: bool,
}

const BLOCK: usize = 4096;

fn main() -> Result<()> {
    let args = Args::parse();
    let profile = load_profile(&args.profile)?;
    let (mut left, mut right) = read_stereo(&args.input)?;
    let len = left.len();

    let mut processor = if args.bypass {
        Processor::with_mask(Box::new(UnityMask), SAMPLE_RATE)?
    } else {
        Processor::new(&profile, SAMPLE_RATE)?
    };
    let latency = processor.latency_samples();

    // Flush the pipeline with `latency` zeros, then drop the first `latency` samples so the
    // output lines up with the input and has the same length.
    left.resize(len + latency, 0.0);
    right.resize(len + latency, 0.0);
    let start = Instant::now();
    for (l, r) in left.chunks_mut(BLOCK).zip(right.chunks_mut(BLOCK)) {
        processor.process(l, r);
    }
    let elapsed = start.elapsed();

    write_stereo(&args.output, &left[latency..], &right[latency..])?;

    let frames = (left.len() / HOP).max(1);
    println!(
        "profile      {} ({})",
        profile.name,
        if args.bypass { "bypass" } else { "static EQ" }
    );
    println!(
        "input peak   {:>7.2} dBFS",
        peak_db(&left[..len], &right[..len], 0)
    );
    println!("output peak  {:>7.2} dBFS", peak_db(&left, &right, latency));
    println!(
        "time/frame   {:>7.1} µs (10 ms of audio)",
        elapsed.as_secs_f64() * 1e6 / frames as f64
    );
    Ok(())
}

fn load_profile(arg: &str) -> Result<Profile> {
    let path = if arg.ends_with(".json") || Path::new(arg).exists() {
        PathBuf::from(arg)
    } else {
        Path::new("profiles").join(format!("{arg}.json"))
    };
    let json = std::fs::read_to_string(&path)
        .with_context(|| format!("reading profile {}", path.display()))?;
    Profile::from_json(&json).with_context(|| format!("parsing profile {}", path.display()))
}

fn read_stereo(path: &Path) -> Result<(Vec<f32>, Vec<f32>)> {
    let reader = WavReader::open(path).with_context(|| format!("opening {}", path.display()))?;
    let spec = reader.spec();
    if spec.sample_rate != SAMPLE_RATE {
        bail!(
            "{}: sample rate is {} Hz; only 48000 Hz is supported (resample first)",
            path.display(),
            spec.sample_rate
        );
    }
    if !(1..=2).contains(&spec.channels) {
        bail!(
            "{}: {} channels; only mono or stereo is supported",
            path.display(),
            spec.channels
        );
    }
    let samples: Vec<f32> = match spec.sample_format {
        SampleFormat::Float => reader.into_samples::<f32>().collect::<Result<_, _>>()?,
        SampleFormat::Int => {
            let scale = 1.0 / (1i64 << (spec.bits_per_sample - 1)) as f32;
            reader
                .into_samples::<i32>()
                .map(|s| s.map(|v| v as f32 * scale))
                .collect::<Result<_, _>>()?
        }
    };
    Ok(if spec.channels == 1 {
        (samples.clone(), samples)
    } else {
        samples
            .as_chunks::<2>()
            .0
            .iter()
            .map(|&[l, r]| (l, r))
            .unzip()
    })
}

fn write_stereo(path: &Path, left: &[f32], right: &[f32]) -> Result<()> {
    let spec = WavSpec {
        channels: 2,
        sample_rate: SAMPLE_RATE,
        bits_per_sample: 32,
        sample_format: SampleFormat::Float,
    };
    let mut writer =
        WavWriter::create(path, spec).with_context(|| format!("creating {}", path.display()))?;
    for (&l, &r) in left.iter().zip(right) {
        writer.write_sample(l)?;
        writer.write_sample(r)?;
    }
    writer
        .finalize()
        .with_context(|| format!("writing {}", path.display()))
}

fn peak_db(left: &[f32], right: &[f32], skip: usize) -> f32 {
    let peak = left[skip..]
        .iter()
        .chain(&right[skip..])
        .fold(0.0f32, |m, v| m.max(v.abs()));
    20.0 * peak.max(1e-10).log10()
}
